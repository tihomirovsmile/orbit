# Безопасность

Orbit — завершённый эксперимент без дальнейшей поддержки и гарантий. Исправления безопасности автором не планируются. Используйте собственную оценку перед публичным размещением.

Не публикуйте базы пользователей, переписки, ключи провайдеров, файлы окружения и ключ шифрования. Для доступа через интернет настройте HTTPS и защищённое размещение. Провайдер ИИ получает отправляемые ему сообщения согласно своим условиям.
